# Pílulas de Ouro
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
HTML, CSS e JavaScript estáticos, conforme formato-curso-v2 escolhido pelo usuário. GitHub Pages no próprio repositório; catálogo INEMA atualizado via Git.

## Users
Pessoas que querem transformar tarefas com IA em projetos úteis. Hipótese editorial: leitor com familiaridade básica com arquivos e navegador, sem exigência de programação avançada.

## Product Purpose
Ensinar a delimitar, produzir e verificar entregas com IA. Cada módulo termina com uma prática e uma evidência de conclusão.

## Capabilities and Constraints
Quatro trilhas, doze módulos e setenta e dois tópicos. Leitura sem login; progresso, dúvidas, marcações, notas, exportação e importação no navegador. O texto continua acessível se JavaScript ou armazenamento estiverem indisponíveis. Publicar apenas material próprio do curso. Arquivos privados de preparação ficam fora do repositório.

## Brand Commitments
Formato INEMA v2 escolhido pelo usuário: dark âmbar, cores por trilha, diagramas conceituais, navegação completa, modos de leitura.

## Product Principles
Uma entrega por vez; dados ausentes continuam ausentes; exemplos fictícios identificados; explicação acompanha a prática; conclusão exige verificação.

## Accessibility & Inclusion
Navegação por teclado, foco visível, contraste AA, temas de leitura, tamanho de texto ajustável e layout móvel.
