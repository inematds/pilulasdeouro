# Práctica 2.3 — Diagramas que explican de verdad

## Entrega

Un mapa de flujo editable acompañado de una explicación simple.

## Ejercicio

Crea un flujo para el pedido descrito en el apartado. Identifica la decisión, el retorno y la salida. Explica cómo se comporta el dibujo cuando falta el contacto.

## Criterios

- [ ] El diagrama corresponde al enunciado.
- [ ] El pedido incompleto tiene un camino explícito.
- [ ] Existe una representación editable.
